# RocketReken

RocketReken is een rekengame waarbij je zo snel mogelijk de goede antwoorden moet geven.  
Voor elk goed antwoord krijg je punten. Hoe sneller en beter je rekent, hoe hoger je score wordt!

Het doel van de game is om je rekenvaardigheid te verbeteren op een leuke en uitdagende manier.
